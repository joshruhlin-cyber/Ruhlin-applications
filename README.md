# Ruhlin Applications

A home for small, self-contained web apps — each one lives in its own folder.

## Apps

- [`up-the-river/`](./up-the-river) — Score-keeping app for *Up the River, Down the River* (a.k.a. Oh Hell). Track players, bids, tricks won, and running totals across a full round.
- [`step-squad/`](./step-squad) — Social step-count feed for friends and family. Steps sync from Apple Health through an iOS Shortcut, with squads, a live leaderboard, milestones, and cheers. Backed by Supabase; try `?demo=1`.
